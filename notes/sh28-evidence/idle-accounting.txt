The idle fixture now uses the explicitly allowed child-only alternative:
PR_SET_THP_DISABLE with value 1, flags 0, in the pty child before exec.
PR_GET_THP_DISABLE must return 1; /proc/PID/status THP_enabled must remain
0 after exec; AnonHugePages must remain 0 in both snapshots. The setting
is documented to survive exec and affects this fixture process, not global
THP controls. No sysfs write, setarch, host configuration or pelt change.
setpriv did not offer the option; the launcher invokes libc's public prctl
ABI directly using Python ctypes. Constants 41/42 are independently decoded
as PR_SET_THP_DISABLE/PR_GET_THP_DISABLE in logs/thp-prctl-trace.log.

PR_SET_THP_DISABLE(2const), PR_GET_THP_DISABLE(2const); no implementation
source read.
